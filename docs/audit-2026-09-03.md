## 当前优势

- 不要求用户复制 Cookie 或安装本地引擎。
- Chrome、Edge、Firefox 共用一套扩展核心。
- 有树状选择、下载队列、重试和目录安全处理。
- 有 GitHub Actions、预发布包、README、隐私、安全和贡献文档。
- `AGENTS.md` 定义了可机器读取的安装准备流程。

## 当前不足

- 只有 Node 单元测试，尚无真实登录态的四浏览器端到端测试。
- 章节动态接口可能需要针对不同学校部署增加适配器；通用 GET/DOM 扫描不能保证覆盖所有部署。
- 当前 Firefox 方案是临时加载，正式版长期安装仍需 Mozilla 签名。
- Safari 只有 WebExtension 资源，没有可签名的 macOS App 封装。
- 免商店安装受浏览器安全策略限制，Agent 不能替用户静默确认加载。
