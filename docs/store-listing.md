# 商店提交资料草案

## 名称

学习通课程资料批量下载

## 简短描述

扫描学习通资料和章节附件，按原目录逐个下载课程文件。

## 详细描述

学习通课程资料批量下载器是一款本地运行的跨浏览器扩展。用户在浏览器中登录学习通并打开课程后，可以扫描“资料”栏目及“章节”下小节中的可下载附件，在树状目录中选择文件或文件夹，逐个直接下载到系统下载目录。程序会保留课程、资料来源、章节和小节结构，支持失败重试、暂停和取消。

扩展不会上传课程资料，不会导出 Cookie，不会绕过验证码、访问控制或 DRM。它只处理当前登录账号有权访问且页面提供直接下载地址的文件；没有直接下载地址的受保护媒体不在范围内。

## 权限说明

- `downloads`：创建和管理用户主动发起的下载任务。
- `tabs`：向用户当前活动的课程页面发起扫描。
- `storage`：保存界面偏好，不保存账号或课程内容。
- 学习通站点权限：读取课程页面和同源资料接口。

## 审核员测试说明

1. 登录一个有权限访问的学习通测试账号。
2. 打开一个课程页面并点击扩展图标。
3. 点击“扫描当前课程”。
4. 选择一个小文件夹或几个附件并点击“开始下载”。
5. 验证浏览器下载目录中出现 `课程名/资料` 或 `课程名/章节` 路径。

测试账号和课程资料不能写入仓库；提交审核时由发布者在对应商店后台按要求提供。
